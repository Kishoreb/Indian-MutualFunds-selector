## Supporting code

`benchmark.BenchmarkProvider` is the runtime side of F009. It resolves and caches one benchmark per category. The `_load` method implements the three-step fallback: local CSV file (written by `import_tri.py`), pinned scheme code from `config.BENCHMARKS`, or auto-discovery of the plain Direct-Growth index fund with the longest NAV history. Auto-discovery filters by keywords, excludes momentum/quality/ETF/FoF variants using `config.BENCHMARK_EXCLUDE_WORDS`, and tests up to `config.BENCHMARK_MAX_CANDIDATES` (6) funds, picking the one with the most history.

`benchmark.compute_benchmark_metrics` computes two numbers: `benchmark_excess_return` (fund CAGR minus benchmark CAGR over matched dates) and `rolling_beat_benchmark_pct` (share of rolling windows where the fund beat the benchmark). Both return None when data is insufficient, never a guess.
