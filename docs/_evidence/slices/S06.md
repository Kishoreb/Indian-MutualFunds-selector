### rules
State: observed
- Summary:
  - Stock table parsing: columns are assigned by x-position on the page (hardcoded for A4 at 595.22 points wide). Each holding row is anchored by an ISIN-shaped word in the ISIN column that has numbers on the same line. Names are multi-line blocks assigned to anchors by vertical proximity and gap detection.
  - ISIN validation: every ISIN is checked against the Luhn-based ISIN check digit. For OCR, each ISIN cell is read at several magnifications and segmentation modes. Common OCR look-alikes (O/0, I/1, S/5, B/8, etc.) are substituted only when the check digit then passes. If multiple valid ISINs result, the one needing fewest edits wins, with ties broken by read-count. An ambiguous or invalid ISIN is flagged for manual checking.
  - Number cross-check: for stocks, qty times price must equal value (tolerance 0.02). If one of the three is missing, it is derived from the other two. For mutual funds, three cross-checks: units times NAV equals valuation, valuation minus invested equals profit/loss, and profit/loss divided by invested equals the profit/loss percentage. Rows that fail are flagged in a "Check" column (yellow in the sheet).
  - Reconciliation: stock totals per demat account are compared with the "Portfolio Value" line printed in the statement. Mutual fund totals are compared with the "Grand Total" row.
  - Demat account attribution: DP Name markers ("DP Name : X   BO ID : ...") assign each subsequent stock row to that demat account.
  - Early stop: the stock section stops when 2 consecutive pages have no rows, or when "MUTUAL FUND UNITS HELD AS ON" is found. The mutual fund section stops when a "Grand Total" row is found.

### failure
State: observed
- Summary:
  - No holdings found: `sys.exit("No holding rows were found. Try --force-ocr, a higher --dpi, or --pages.")` (exit status 1).
  - No mutual fund rows: a printed message, but the program continues (stocks are already written). No error exit.
  - Missing Tesseract: `sys.exit("This PDF page has no text layer, so OCR is needed:...")` when `pytesseract` is not installed and a page needs OCR.
  - Missing `xlwt` or `openpyxl`: `sys.exit` when the chosen output format's library is not installed.
  - No per-row recovery or retry: each page is processed once. Rows with failed cross-checks are written with a flag, not dropped.
