## Supporting code

`forward_signals.py` defines two groups of signals:

1. **NAV-derived** (5 signals, always computable from price history): `sharpe_stability` (worst-half Sharpe), `rolling_p10` (10th-percentile rolling return), `rolling_dispersion` (p90-p10), `beta_drift` (std of rolling beta), `down_capture_drift` (std of rolling down-capture). Each returns None when data is insufficient.

2. **CSV-based** (4 signals from `fund_attributes.csv`): `expense_ratio`, `aum_strain` (a size-times-growth composite), `manager_tenure_years`, `turnover_pct`. The CSV is validated (out-of-range values become NaN with a warning), checked for staleness, and merged by scheme_code.

The forward tilt is a weighted average of standardized signals (same standardization as the main scorer). It is blended with the backward composite score to produce `combined_score`, which re-ranks the funds when enabled.

The `backtest.py` module tests each signal by Spearman rank correlation on a grid of past dates, but it cannot currently run.
