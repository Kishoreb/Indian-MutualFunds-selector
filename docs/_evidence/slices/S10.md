### rules
State: observed
- Summary:
  - Sheet parsing: rows after the header until "Grand Total" are classified as equity (ISIN matches `INE____01___`), cash (TREPS, CBLO, net receivables, etc.), derivative (futures, options, margin), other, total or skip. Rows after Grand Total are ignored.
  - Weight scaling: if the sum of non-derivative row weights is 0.9-1.1, the weights are treated as fractions and multiplied by 100. The final sum must be within `config.PQ_SUM_TOLERANCE` (configurable around 100%); otherwise the sheet is not scored ("weights sum to X%, not ~100%").
  - Five sub-criteria, each mapped to 0-100 by a linear function between a "worst" and "best" value from `config.PQ_CRITERIA`:
    1. `top10_pct`: % of NAV in the 10 largest equity holdings (lower is better)
    2. `n_holdings`: number of equity holdings (higher is better)
    3. `top_sector_pct`: % of NAV in the largest industry (lower is better; requires 80% of rows to have an industry)
    4. `largemid_pct`: % of equity in large+mid caps from the AMFI map (higher is better; requires a minimum match fraction)
    5. `cash_pct`: cash, TREPS and net receivables % of NAV (lower is better)
  - `portfolio_quality` = weighted average of the sub-scores that could be measured. If the measurable weight is below `config.PQ_MIN_COVERAGE`, the score is None (missing). Fewer than `config.PQ_MIN_EQUITY_HOLDINGS` (10) equity holdings also gives None.
  - Scheme matching: `PortfolioIndex.lookup` matches a scheme name by normalising (dropping parenthetical text, plan/option words, punctuation) and checking exact or fuzzy match (threshold `config.PQ_NAME_MATCH_RATIO`). The newest statement wins. Ambiguous fuzzy matches return None.
  - Staleness: if the statement's "as on" date is older than `config.PQ_MAX_AGE_DAYS`, the score is None ("statement is stale").

### Conclusion
- Does: parses SEBI-style portfolio statements from AMC workbooks, computes a documented 0-100 portfolio-quality score from five sub-criteria (concentration, diversification, sector exposure, liquidity, cash), and provides it as a metric for the scoring engine.
- Rules: equity ISIN pattern `INE____01___`; linear 0-100 mapping per sub-criterion between configurable worst/best thresholds; weighted average with a coverage floor; fraction-to-percent auto-detection; staleness check; fuzzy scheme-name matching with ambiguity rejection.
- On failure: always returns None with a reason string; never crashes or guesses.
- Test result: well tested
- Tests check: exact rubric re-computation against an independent calculation, every sub-criterion input, every failure path (few holdings, bad weights sum, stale, unmatched, coverage floor), market-cap criterion with full and partial coverage, name normalisation and row classification, shortlist integration with partial data, zip extraction with path-traversal defence.
- Known gaps: no test for real AMC workbooks (only synthetic ones); the industry-sector grouping depends on AMC-provided strings which vary in spelling across fund houses.
- Search boundary: `test_portfolio_quality.py` is the only file covering this module.
